# متجر الفخامة | Al Fakhamah

متجر إلكتروني عربي RTL بتصميم أسود وذهبي، مبني بـ PHP 8+ وMySQL.

## البنية
- `public/`: جذر الموقع الذي يُرفع إلى `htdocs`.
- `public/assets/`: CSS وJavaScript.
- `public/api/`: واجهات JSON للمنتجات.
- `public/admin/`: لوحة الإدارة وإدارة المنتجات والأقسام والبانرات والطلبات.
- `database/schema.sql`: مخطط قاعدة جديدة.
- `database/migrate-existing.sql`: ترقية قاعدة المشروع القديمة.

## الإعداد على InfinityFree
1. أنشئ قاعدة MySQL من لوحة InfinityFree.
2. أدخل DB Host وDB Name وDB User وDB Password في `public/config.php`. بيانات FTP مختلفة عن بيانات MySQL.
3. لقاعدة جديدة فارغة: استورد `database/schema.sql` من phpMyAdmin.
4. لقاعدة المشروع القديمة: خذ نسخة احتياطية ثم نفّذ `database/migrate-existing.sql` مرة واحدة.
5. غيّر `ADMIN_SETUP_KEY` في `public/config.php` إلى قيمة طويلة عشوائية.
6. بعد النشر افتح `/admin/setup.php` وأنشئ أول مدير بكلمة مرور لا تقل عن 12 حرفاً، ثم احذف `public/admin/setup.php` من المستودع.
7. سجّل الدخول عبر `/admin/login.php` وأضف منتجاتك وصورها ومخزونها وبانراتك.
8. GitHub Actions يرفع محتويات `public/` كاملة إلى `/htdocs/` دون استثناءات.

## المزايا
- بانرات متحركة تلقائياً.
- دوّار أقسام يتمركز عند القسم المختار: 8 أقسام تقريباً على الكمبيوتر و3 على الهاتف.
- تحديث المنتجات دون إعادة تحميل الصفحة.
- صفحات تفاصيل المنتج والبحث والسلة وإتمام الطلب.
- حسابات العملاء وسجل الطلبات للحساب المسجل.
- لوحة إدارة للمنتجات والأقسام والبانرات والطلبات.
- رفع صور محمي للمدير (JPG/PNG/WEBP/GIF، حتى 5MB).

## حدود التكامل الحالي
الطلب يسجل كدفع عند الاستلام ويحتاج تأكيداً هاتفياً. لا توجد بوابة دفع إلكتروني أو خدمة SMS؛ ربطهما يتطلب مزوداً خارجياً ومفاتيح منفصلة. لا تضع أسرار MySQL أو مفتاح التهيئة في مستودع عام.
