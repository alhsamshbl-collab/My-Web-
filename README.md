# متجر الفخامة | Al Fakhamah

متجر إلكتروني عربي RTL بتصميم أسود وذهبي، مبني بـ PHP 8+ وMySQL.

## ملفات المشروع
- `public/`: ملفات الموقع التي تُرفع إلى مجلد `htdocs`.
- `public/admin/`: لوحة الإدارة وإدارة المنتجات والأقسام والبانرات والطلبات.
- `public/api/`: واجهات JSON.
- `database/schema.sql`: ملف إنشاء قاعدة جديدة كاملة (ملف SQL واحد).
- `database/migrate-existing.sql`: ترقية قاعدة المشروع القديمة فقط.

## إنشاء قاعدة البيانات على InfinityFree
1. أنشئ قاعدة MySQL واحدة من لوحة InfinityFree، ثم افتح phpMyAdmin الخاص بها.
2. افتح تبويب Import واستورد الملف `database/schema.sql` من GitHub. هذا ينشئ الجداول السبعة: `categories`, `products`, `banners`, `customers`, `orders`, `order_items`, `admins`، ويضيف ستة أقسام افتراضية.
3. لا تستورد `migrate-existing.sql` فوق قاعدة جديدة؛ هذا الملف للترقية فقط. خذ نسخة احتياطية قبل تشغيله على قاعدة قديمة.
4. أدخل بيانات MySQL التي تعرضها الاستضافة في `public/config.php`. بيانات FTP ليست بيانات MySQL.
5. غيّر `ADMIN_SETUP_KEY` في `public/config.php` إلى مفتاح طويل وعشوائي لا تشاركه مع أحد. لا تترك القيمة الافتراضية.
6. بعد نشر الموقع افتح `/admin/setup.php`، وأدخل مفتاح التهيئة واسم المدير وبريده وكلمة المرور وتأكيدها. يجب أن تكون كلمة المرور 12 حرفاً على الأقل. تنشئ الصفحة مديراً واحداً فقط وتُغلق تلقائياً بعد ذلك.
7. بعد نجاح إنشاء المدير، احذف `public/admin/setup.php` من المستودع ومن الاستضافة. سجّل الدخول من `/admin/login.php` باستخدام البريد وكلمة المرور.
8. من لوحة الإدارة أضف منتجاتك وصورها وأسعارها ومخزونها وبانراتك.

## النشر
GitHub Actions يرفع محتويات `public/` إلى `/htdocs/` باستخدام أسرار FTP التالية: `FTP_SERVER`, `FTP_USERNAME`, `FTP_PASSWORD`, `FTP_PORT`. لا يرفع مجلد `database/` لأنه ملف استيراد يدوي إلى phpMyAdmin. نجاح رفع FTP لا يعني أن قاعدة MySQL قد أُنشئت أو اتصل بها الموقع.

## وظائف المتجر الحالية
- بانرات متحركة تلقائياً.
- دوّار أقسام واختيار قسم لتحديث المنتجات دون إعادة تحميل الصفحة.
- تفاصيل المنتج والبحث والسلة وإتمام الطلب.
- حسابات العملاء وسجل الطلبات.
- لوحة إدارة للمنتجات والأقسام والبانرات والطلبات.
- رفع صور محمي للمدير (JPG/PNG/WEBP/GIF، حتى 5MB).

## ملاحظات مهمة قبل التشغيل الفعلي
- ملف SQL يحتوي بنية الجداول والأقسام الافتراضية، لكنه لا يحتوي منتجات حقيقية أو صوراً أو طلبات/عملاء فعلية؛ أضف بيانات منتجاتك من لوحة الإدارة.
- الدفع الحالي عند الاستلام فقط، ولا توجد بوابة دفع إلكتروني أو تكامل SMS.
- يجب اختبار الاتصال بقاعدة البيانات، وتسجيل حساب، وإضافة منتج، وإجراء طلب تجريبي على الاستضافة قبل اعتبار المتجر جاهزاً للإنتاج.
- لا تضع أسرار MySQL أو مفتاح التهيئة في مستودع عام. الأفضل نقل الإعدادات إلى ملف إعداد خاص خارج مجلد الويب إن كانت الاستضافة تسمح بذلك.
